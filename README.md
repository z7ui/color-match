# 选色助手（color-match）

装修选色对比：**家里的照片当基准**（原样不动），把工地拍的照片拉到家里的光线下，
判断瓷砖、门、美缝到底是不是同一个颜色。

- 文章：<https://www.z7ui.cn/color-match/>
- 下载：<https://www.z7ui.cn/tile-api/apk/color-match/>

## 核心逻辑（重要）

```
家里的照片  ──► 只测一个白点数值，照片本身永远不动（基准）
工地的照片  ──► 测白点 ──► 拉到家里的白点 ──► 和家里的原图比 ΔE
```

- **参照（家里）是基准，任何一步都不会修改它的画面**。它既不会被「标定成纯白」，
  也不会生成第二张校正图——因为那正是你要拿来对比的东西。
- **标定 = 测白点**：框一块白纸，记下它的 RGB，仅此而已（不重写照片，瞬间完成）。
- **对比 = 把工地的白点搬到家里的白点上**：输出「这块砖搬回我家、在我家灯下大概是什么样」，
  并给出校正前后的 ΔE00。

## 功能

- **拍照**：全屏预览 + 构图引导（中间主体框、左下角白纸框），支持切换前后摄
- **上传**：从相册选图（Android 13+ 走系统照片选择器）
- **标定**：拖动/缩放选框，实时显示平均色与块内均匀度；按 A4 灰阶靶的指标提示「这块白能不能用」
- **对比**：
  - 校正前 ΔE —— 两张**原始照片**直接比（你在两个现场各自看到的差异）
  - 校正后 ΔE —— 工地拉到家里光线后比（排除光源差异后的真实色差）
  - 改善比例、多目标切换、按住看原图
- **存储**：SQLite（会话 / 采集 / 对比），照片存应用内部目录
- **自检（误差下限）**：标定时可再框一块「已知物」（灰卡中灰 / 同一块样板），
  两张图放同一件东西 → 算出这套流程的分辨力；结果区显示 `误差下限 ΔE` 与 `可信差异`
- **多光源复检**：每张照片可打「光」的标签（家里顶灯 / 窗边 / 门店射灯…），
  同一块样品换几个光源拍，ΔE 不稳就是同色异谱
- **详情页**：单组对比一页看全（三张图 + 白点 / 已知物 / 误差下限 / 光源 / 补光 / 时间）
- **导出**：每行「家里 | 工地原图 | 工地拉到家里后」+ 中文标注（ΔE、误差下限、地点、日期），写应用目录并另存相册
- **数据管理**：数据库备份 / 恢复、CSV / JSON 导出（CSV 带 BOM，Excel 直接开）
- **补光**：采集页可开手电筒常亮（默认关），是否补光会记进照片元数据
- **诊断**：ADB 意图或口令控制台（关于页连点版本号 7 次），白名单命令 + 孤儿文件清理；任意 shell 仅 debug 构建
  
- **关于页**：版本、检查更新、公告、权限说明

## 算法

**白点迁移**（只作用于工地那张；在线性光空间做）

```
增益 = lin(家里白点) / lin(工地白点)      // 夹在 0.1 ~ 12 之间
输出 = sRGB( lin(工地像素) × 增益 )
```

**色差**：sRGB → 线性 RGB → XYZ(D65) → Lab → CIEDE2000（与 Sharma 参考数据对齐，单测校验）。

判定参考（沿用 A4 灰阶靶工具包）：

| 指标 | 阈值 |
|---|---|
| 白参考亮度 | ≥ 235 |
| 光照梯度 | ≤ 6 |
| 块内跨度 | ≤ 15 |

## 工程约定

- **图像重活全部在后台 isolate**（`lib/core/image_pipeline.dart`）：解码、EXIF 摆正、迁移、拼图、JPEG 编码；
- **EXIF 统一摆正**（`bakeOrientation`），避免「预览是竖的、采样到的是横的」；
- **标定只写白点**，不产生任何校正图；
- **重新标定会让旧对比失效**；**删参照会连带删掉以它为基准的对比**；
- 数据库改动走事务；有 `android/key.properties` 就用正式签名，没有回退 debug。

## 构建

```bash
flutter pub get
flutter analyze            # 期望 0 / 0 / 0
flutter test               # 18 个用例
flutter build apk --release --target-platform android-arm64
```

服务器地址编译期定死（默认 `https://www.z7ui.cn/tile-api`），要换环境：

```bash
flutter build apk --release --dart-define=API_BASE_URL=https://你的地址
```
